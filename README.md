# Azure SOC Labs

Bienvenido a mi portafolio de laboratorios de Microsoft Azure enfocados en Ciberseguridad.

## Sobre este proyecto

Este repositorio documenta mi proceso de aprendizaje práctico en Azure y Microsoft Sentinel con el objetivo de fortalecer mis conocimientos en ciberseguridad

Cada laboratorio incluye:

- Objetivo
- Arquitectura
- Procedimiento
- Capturas de pantalla
- Consultas KQL
- Resultados
- Lecciones aprendidas

## Tecnologías

- Microsoft Azure
- Microsoft Sentinel
- Log Analytics
- Kusto Query Language (KQL)
- Microsoft Defender
- Microsoft Entra ID
